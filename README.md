# Real-Time Chat Application

A simple real-time chat application built using Node.js, Express.js, Socket.IO, HTML, CSS, and JavaScript.

## Features
- Real-time messaging between connected users
- User join and leave notifications
- Sound notifications for incoming messages

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Socket.IO

## How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Shweta74906/Real-Time-Chat-Application.git
   ```

2. Open the project folder:
   ```bash
   cd Real-Time-Chat-Application
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the application:
   ```bash
   npm start
   ```

5. Open `http://localhost:3000` in your browser. If your server uses a different port, use the port configured in `server.js`.

## Project Overview
This project demonstrates real-time communication between multiple connected browser clients using Socket.IO and a Node.js backend.
